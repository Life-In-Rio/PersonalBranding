# B.E Profile. — Personal Portfolio Website

A modern, minimalist, and interactive personal portfolio website designed and developed by **Abyan Eshan** to showcase selected web and mobile development projects, technical skills, and contact channels.

🔗 **Live Demo:** https://beeprofile.netlify.app/

---

## ✨ Key Features

- **4-Layer Sticky Stacking Layout:** Smooth card-stacking scroll transitions (`Hero` → `About` → `Projects & Tech Stack` → `Contact`) with curved section dividers and depth shadows.
- **Floating Glassmorphism Navbar:** Dynamic section-aware navigation with smooth anchor scrolling across stacked layers.
- **Infinite Project Marquee:** Auto-scrolling showcase featuring live site previews and GitHub repository links, pausing smoothly on hover.
- **Interactive Tech Stack Badges:** Brand-colored hover states with synchronized zoom and 360° icon rotation transitions.
- **Liquid Distortion Signature Footer:** Interactive SVG turbulence distortion effect on pointer movement.
- **Dynamic Tab Visibility:** Custom SVG favicon (`B.E`) and playful `"Comeback 👋"` tab title when switching browser tabs.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile viewports.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3
- **Animations & Icons:** Framer Motion, Lucide React, React Icons
- **Deployment:** Netlify
